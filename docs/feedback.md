# Feedback

Every report from a friend, newest first, written the same day (ship-bob `feedback-loop.md` 2).
"Who" is an initial: this file is public with the repo. Kind: `crash | sound | cpu | install | ux`.
Severity: `blocks | annoys | cosmetic`. State: `new -> asked -> reproduced -> fixed <version> |
wont-fix EX-nnn | not-a-bug`, ending with `confirmed <date>` or `no answer after <version+2>`.
"Closed by" names the test, the exception or the README line that keeps it from coming back.
